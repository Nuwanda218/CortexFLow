# 项目首页与应用内标签页 · 2026-11-24

以本轮用户规格替代此前 Project / Conversation 入口。沿用 Vue、TypeScript、Vite、Vue Router、Lucide 和浅色视觉；不重建工程，不改 Core。首页仅五个项目行，每行名称、概况、最近修改日期、最近 Task；无统计、进度、标签或产品说明。

布局：应用栏保留标志和名称，其下为应用内标签栏。首页固定不可关闭，项目按打开顺序追加，重复打开只聚焦。首页主体包含搜索、新建入口和轻量分割的完整项目行；名称/概况居左，Task/日期居右。窄窗口重排元信息，无文档横向溢出。

独立的 HomeProject Mock 模块与项目标签 store 不依赖对话数据。已有内部组件暂留源码，本轮不挂载；项目面板为简单占位。使用独立键和 v-show 保留已打开项目页面实例及首页搜索/滚动；关闭后释放页面。路由仅标识当前标签，直接访问项目路径打开对应标签，旧聊天/工作路径回到首页。

新建项目使用既有 DemoDialog；验证名称和重名，新数据仅在内存中保存。关闭活动项目聚焦右邻标签，否则左邻或首页；关闭后台项目不切活动页。支持方向键、Home/End 及 Delete 关闭项目；首页不可被 Delete 关闭。

验收先写项目首页/标签测试并确认旧界面失败，再实现并构建；检查多标签状态保留、搜索、新建、关闭、窄窗口、页面错误与截图。原先工作页浏览器用例保留为历史用例，不冒充本轮活动界面检查；当前测试入口改为项目首页规格。Mock 身份在源码与交付说明标识，界面按用户要求不增加说明标签。
