## 边界与保留项

- 本次创建 2 个初始 Mock 项目、5 个对话、10 条任务、3 个 Agent，均为虚构演示快照。
- 项目/对话的新增只保存在页面内存中，刷新恢复初始数据。
- Workflow 编辑、排序和补充 Task 也仅在本地页面内存保存。原有执行历史在计划更新中保留；显式重置演示恢复初始快照。
- 每个初始 Project 对应一份 Workspace Workflow；新增项目没有自动生成的规划。没有后端状态机、DAG、LLM 规划或工作流版本管理。
- 未修改既有 Core、Bridge、扩展或 C-06 逻辑，也未修改原有根目录文档。仓库原先存在的未提交内容保留。
- 未集成真实 ChatGPT、Electron、Python Core、数据库或任务接口；本记录不能证明真实 Agent 执行能力。
- 本轮已验证桌面浅色界面与 900px 窄窗口；不将手机端、完整无障碍认证或其他操作系统的未执行测试写成通过。
