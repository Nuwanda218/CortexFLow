# 协作消息顺序泳道

用户要求工作页以顺序泳道图展示 Agent 之间的信息交流。沿用 ChatGPT 浅色外壳，用纵向时间和横向参与方替换原有静态节点图。

泳道为 Supervisor、Core、Codex CLI、Claude CLI、dsh。交流均通过 Core 路由，只有独立 Mock 消息明确记录的路径才绘制箭头。状态观测画为 Core 泳道内的注记；等待派发画虚线并明确标注未发送。配置状态不等同在线。

支持当前对话和选中任务两种范围；按当前任务状态、Agent、搜索条件过滤消息。点消息选中任务并打开详情，点泳道标题继续筛选 Agent。图内按时间升序且可滚动，窄窗口只让画布横向滚动。

实施：先运行泳道验收用例确认失败，再添加独立消息类型/Mock 模块，替换 AgentFlow 为 AgentSequence，保留任务表和详情，最后运行构建、交互检查与截图目视核验。不接入真实消息链路。
