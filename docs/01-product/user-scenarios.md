# 用户场景与验收场景草案

以下是材料中的示例及其可观察结果，不是已经验证通过的产品用例。来源：[S01-A7](../00-audit/material-audit.md#s01-a7)、[S01-A10](../00-audit/material-audit.md#s01-a10)、[S01-B1](../00-audit/material-audit.md#s01-b1)。

## 典型情境

| 场景 | 用户想做什么 | 材料充分程度 |
| --- | --- | --- |
| 阅读个人软件项目 | 先形成架构模型，再选择值得深入的源码路径 | 有完整七阶段推演 |
| 项目开发 | 讨论方案、让执行工具处理具体工作 | 仅有工作空间举例，修改权限与开发闭环未展开 |
| 课程学习 / 研究 | 在讨论中按需使用其他工具收集材料 | 仅有场景定位，无独立业务流程 |

后两项不能据此扩写成自动写代码、检索互联网或多人研究系统等额外功能。

<a id="ac-01"></a>
## AC-01：与 ChatGPT、Codex 协作阅读刷题网站

参与者：用户提出目标并确认；ChatGPT 讨论与规划；Codex 读取本地源码。前提是接入能力可用、工作空间与会话关系明确、结果接收策略已选定；目前这些前提尚未全部验证。

| 步骤 | 用户动作 / 系统可观察行为 | 相关需求 |
| --- | --- | --- |
| 1 | 打开工作空间，在统一输入框提出“从宏观角度理解项目” | FR-01、FR-19 |
| 2 | ChatGPT 正常讨论阅读顺序；系统在已选触发方式下生成只读扫描草案 | FR-03、FR-24；触发方式见 Q04 |
| 3 | 草案可查看、修改、拒绝；用户确认前不能下发 | FR-04、FR-05 |
| 4 | 确认后 Codex 收到任务；用户不必复制提示词或切换执行工具窗口 | FR-05 |
| 5 | 执行期间用户继续与 ChatGPT 讨论；未返回结果不被当成源码证据 | FR-01、FR-20 |
| 6 | 完成后消息流出现结果摘要，任务图反映完成，详情可查看输入、输出和日志 | FR-02、FR-06、FR-11、FR-14 |
| 7 | 结果按接收策略回传 ChatGPT；不适合发送时保持待发送，而不是假定 ChatGPT 已收到 | FR-07、FR-08 |
| 8 | 收到结果后可继续讨论下一步；新的执行任务仍受确认约束 | FR-04、FR-24 |
| 9 | 切换消息泳道，点击消息或任务查看关联详情 | FR-13、FR-15 |

原稿中的 Flask、JavaScript、SQLite 是刷题网站场景的示例输出，**不是 ContextFlow 技术选型**。示例扫描的“不修改文件、不访问真实用户数据”是该任务的限制，不是对所有未来任务一律只读。

<a id="ac-02"></a>
## AC-02：后台结果不打断当前讨论

来源：[S01-C1](../00-audit/material-audit.md#s01-c1)、[S01-C4](../00-audit/material-audit.md#s01-c4)。

在用户主动暂缓后台消息的条件下，执行任务完成：结果仍可查看，任务标记完成；需要回传的内容进入队列，而不是直接插入 ChatGPT 对话。用户可预览、延后、手动发送或取消发送。队列操作细节仍为候选（Q15）。

关联：FR-07–FR-10、FR-18。通过条件是“结果可用、发送尚未发生、用户保持控制”，不是要求系统能检测用户正在思考。

<a id="ac-03"></a>
## AC-03：按需切换注意力

来源：[S01-A2](../00-audit/material-audit.md#s01-a2)、[S01-C3](../00-audit/material-audit.md#s01-c3)。

任务运行时，用户调整三栏或切换候选布局预设，聚焦对话、流程或执行详情；随后恢复全局视图。切换期间任务不被暂停、会话不被更换；同一工作空间重新打开时可恢复布局。

关联：FR-16、FR-17；后台静默另由 FR-18 控制。不能把“专注对话布局”自动解释为“已打开消息静默”，联动默认值见 Q10。

<a id="ac-04"></a>
## AC-04：失败可见但不自动扩大执行

来源：[S01-A3](../00-audit/material-audit.md#s01-a3)、[S01-A5](../00-audit/material-audit.md#s01-a5)、[S01-A6](../00-audit/material-audit.md#s01-a6)。

执行工具报告失败后，消息流可辨认异常，流程节点反映失败，详情保留错误信息。下一步是否重试、修改任务、切换工具或处理依赖尚未决策（Q08），不将任一恢复策略写入通过条件。

关联：FR-23、NFR-02。此场景验证已有的异常可见性，不补造自动恢复流程。
