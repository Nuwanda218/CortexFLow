## 首版非目标 / 暂不纳入的能力

- 不替代成熟 AI 工具，不追求最大化自动化或 Agent 数量（产品定位）。
- 复杂循环控制、条件表达式与自动执行脚本：原稿明确“不建议第一版加入”，作为边界建议保留（[S01-A4](../00-audit/material-audit.md#s01-a4)，L243）。
- 多执行 Agent 并行、多网页产品接入、自动连续调度：原稿列为后续扩展；后段概念图不足以改变首版范围。
- 跨设备协作：原稿“暂不考虑”，不是永久禁止。
- 拖拽依赖、画布创建任务：原稿未决；不纳入首版必需能力，也不宣称用户已确定只读（Q13）。

**画布展示并行关系（FR-12）不等于首版已经支持多个执行 Agent 并行运行。** 并行任务结果组织与回传见 Q05。

## 尚未定义的边界

多步骤确认粒度、网页接入、会话映射、结果回传时机、完整消息保存、失败后的恢复、暂停取消语义均未定案。来源与影响统一见[未决问题](../02-requirements/open-questions.md)，避免在范围层各自补默认值。
