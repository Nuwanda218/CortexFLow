- 核心目标：降低跨工具转发、窗口切换、状态追踪与协调负担，并保护用户理解和控制权。
- 核心能力方向：自然交流、结构化任务草案、确认后分发、结果收集与回传、独立消息队列、双视图、按需详情和灵活工作台。
- 首版建议：原稿以 ChatGPT + 一个 CLI Agent 为首个集成目标；完整首版界面与第一次验证的范围需区分。队列、预设与上下文等版本归属仍待批准。
- **历史材料中没有可独立核验的用户明确确认产品条款**。上述方向不能对外称为最终确认需求。
- 转述待核验：历史 / 计划共存、泳道概览 / 详情、自然语言与独立提取、已认可三栏、队列与自由聚焦等。
- AI 候选：自动提取、三种接收模式及默认智能、B+C 空闲判断、四预设、独立静默、系统泳道默认隐藏、摘要回传与全文引用等。
- 技术假设：网页消息读写与自动续答、执行工具控制能力、完整报告的可访问性。架构没有将它们写成已可用组件。

## 4. 缺口与重要张力

以下并不是“已确认需求被漏写”，而是原材料自身缺乏批准证据或行为契约：

1. **控制契约**：多步确认、任务修改后授权、暂停 / 取消生效、失败恢复和依赖处理（Q01、Q08）。
