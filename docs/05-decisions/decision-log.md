# 决策与重要方案记录

这是一份**状态台账**，不把“出现在设计稿”视为“用户已决定”。当前没有历史产品决策达到用户明确确认等级；转述项与 AI 候选分开记录。来源时间仅能确定 S01 内顺序，无法还原每次反馈日期。

如需批准某方案，应补用户原话 / 批准记录，并只更新对应条目。冲突来源见[材料审计 H01–H04](../00-audit/material-audit.md#5-历史方案的冲突--设计张力)。

<a id="d01"></a>
## D01 协调既有工具，不替代工具

- **内容**：定位为协作工作台，降低协调与认知负担，而非最大化自动化或 Agent 数量。
- **依据**：工具能力互补，但信息转发、窗口切换和状态追踪仍需用户承担。
- **确认状态**：候选（产品设计稿口径，无用户批准证据）。
- **来源**：[S01-A1](../00-audit/material-audit.md#s01-a1)、[S01-A11](../00-audit/material-audit.md#s01-a11)。
- **影响**：G01–G05、FR-01、FR-02、FR-11、NFR-01；产品边界。

<a id="d02"></a>
## D02 ChatGPT 网页作为当前主要协作者，角色不永久绑定

- **内容**：当前以 ChatGPT 网页端理解目标、讨论与建议；全局调度角色概念上可由其他工具承担。
- **依据**：利用现有工具，并保留角色与工具的区分。
- **确认状态**：候选；网页接入是技术假设（Q02）。
- **来源**：[S01-A1](../00-audit/material-audit.md#s01-a1)，L13；[S01-A6](../00-audit/material-audit.md#s01-a6)，L427；[S01-B1](../00-audit/material-audit.md#s01-b1)，L635–639。
- **影响**：FR-01、FR-07、FR-24、NFR-06；会话映射 Q06。不是选定接入技术。

<a id="d03"></a>
## D03 自然交流与结构化草案提取分离

- **内容**：ChatGPT 不必输出 JSON，独立结构化分析将行动建议变成草案。
- **依据**：保持自然对话体验，避免执行 Agent 对普通聊天文字直接采取行动。
- **确认状态**：转述待核验（A L456 称来自用户）；自动 / 手动触发未决，额外 API 方式未批准。
- **来源**：[S01-A6](../00-audit/material-audit.md#s01-a6)，L454–462；[S01-B1](../00-audit/material-audit.md#s01-b1)，L697–739。
- **影响**：FR-03、FR-04、FR-24、Q04；不升级为自动调用 API 的固定实现。

<a id="d04"></a>
## D04 新执行任务默认经用户确认

- **内容**：用户可接受、修改或拒绝；直接指定 Agent 仍先生成待确认任务。
- **依据**：用户保留执行权，建议不是授权。
- **确认状态**：候选（原稿明确条款，未有批准原话）；多步确认粒度未决。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L160–189；[S01-A6](../00-audit/material-audit.md#s01-a6)，L440–452。
- **影响**：FR-04、FR-05、FR-21–FR-23、NFR-05、Q01。

<a id="d05"></a>
## D05 三栏分工且用户自由聚焦

- **内容**：左栏交流，中栏全局关系，右栏细节；面板可调整、折叠或最大化。
- **依据**：统一工作台不要求用户始终同时注意全部信息。
- **确认状态**：转述待核验（三栏认可见 C L1089，自由焦点反馈见 C L1002）；具体细则候选。
- **来源**：[S01-A2](../00-audit/material-audit.md#s01-a2)、[S01-A11](../00-audit/material-audit.md#s01-a11)、[S01-C2](../00-audit/material-audit.md#s01-c2)、[S01-C4](../00-audit/material-audit.md#s01-c4)。
- **影响**：FR-14、FR-16、FR-17、NFR-01、NFR-07。

<a id="d06"></a>
## D06 流程图同时呈现历史与未来计划

- **内容**：在同一流程图区分实际已发生工作、当前任务和未确认计划；节点为工作步骤而非固定 Agent。
- **依据**：让用户掌握整体推进而不是仅看 Agent 名单。
- **确认状态**：转述待核验（A L247 声称此前 C 方案已确定）；普通对话事件粒度未决。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L219–264；[S01-B1](../00-audit/material-audit.md#s01-b1)，L676–682。
- **影响**：FR-11、FR-12、Q11、H03。

<a id="d07"></a>
## D07 流程图与泳道共享协作事实

- **内容**：流程表达任务关系，泳道表达实际通信，任务与消息双向关联。概览 / 详情分层显示。
- **依据**：回答不同问题，但避免两套独立状态历史。
- **确认状态**：共享状态为候选；概览 / 详情要求为转述待核验（A L311）。系统泳道默认隐藏未确认。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L266–348；[S01-B4](../00-audit/material-audit.md#s01-b4)，L969–981。
- **影响**：FR-13–FR-15、NFR-02、NFR-04、Q14。

<a id="d08"></a>
## D08 结果回传以对话保护与队列为缓冲

- **内容**：减少手动转发；不宜插入时先队列，再由用户或已定策略发送，通知与发送分开。
- **依据**：后台任务结果不应打断当前思路。
- **确认状态**：用户队列 / 自动回传意图为转述待核验；接收判据、三模式与默认值未决。网页自动续答为技术假设。
- **来源**：[S01-B3](../00-audit/material-audit.md#s01-b3)，L918–926；[S01-C1](../00-audit/material-audit.md#s01-c1)、[S01-C5](../00-audit/material-audit.md#s01-c5)。
- **影响**：FR-07–FR-10、FR-18、NFR-03、Q02、Q03、Q10、H02。不能认定 B+C 已获选择。

<a id="d09"></a>
## D09 工作空间相关性与信息来源分离

- **内容**：按项目组织协作；区分原始消息、任务、执行结果、用户确认结论，只传任务相关信息。
- **依据**：减少上下文负担并防止推测被误当事实。
- **确认状态**：候选；会话关系、保存与压缩政策未决。
- **来源**：[S01-A7](../00-audit/material-audit.md#s01-a7)、[S01-B2](../00-audit/material-audit.md#s01-b2)，L813–821。
- **影响**：FR-19、FR-20、FR-24、NFR-04、NFR-05、Q06、Q07。

<a id="d10"></a>
## D10 四种布局建议与静默控制独立

- **内容**：全局协作、专注对话、专注流程、专注执行是面板预设；最大化与静默后台通知分别控制。
- **依据**：视觉空间与注意力中断是两个不同问题。
- **确认状态**：候选（C 明确称建议 / 推导）；默认联动未决。
- **来源**：[S01-C3](../00-audit/material-audit.md#s01-c3)、[S01-C4](../00-audit/material-audit.md#s01-c4)，L1233–1258。
- **影响**：FR-16–FR-18、NFR-03、Q10。

<a id="d11"></a>
## D11 首个集成建议为 ChatGPT 与一个 CLI Agent

- **内容**：原稿完整首版含三栏、消息、双视图、详情、建议与确认；多执行 Agent 并行为扩展，复杂循环 / 条件脚本不建议首版加入。
- **依据**：原稿区分完整首版与第一次原型，避免一次覆盖全部设想。
- **确认状态**：候选；后段并行示意造成范围张力，不视为新批准。
- **来源**：[S01-A9](../00-audit/material-audit.md#s01-a9)、[S01-A4](../00-audit/material-audit.md#s01-a4)，L243；[S01-C4](../00-audit/material-audit.md#s01-c4)，L1279–1285。
- **影响**：FR-05、FR-12、FR-17–FR-21、NFR-06、Q05、Q09、H01。正式范围仅在范围文档维护。

<a id="d12"></a>
## D12 结果摘要与全文访问分层

- **内容**：群聊显示必要摘要，详情查看完整输出；回传建议为摘要附完整报告引用，而非无条件大段源码。
- **依据**：保留可深究性，降低消息与上下文拥挤。
- **确认状态**：候选；保存政策、引用可访问性未验证。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L140–144；[S01-A5](../00-audit/material-audit.md#s01-a5)，L407–415；[S01-B3](../00-audit/material-audit.md#s01-b3)，L882。
- **影响**：FR-02、FR-06、FR-07、FR-14、FR-20、NFR-01、NFR-05、Q07。
