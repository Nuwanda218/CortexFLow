# 非功能需求与质量目标

所有条款均为设计材料中的质量意图或从其行为直接提炼的候选目标，**无历史用户明确确认记录**。P1/P2 为整理建议。验收方式为草案；不虚构延迟、吞吐、可用性或容量指标。

<a id="nfr-01"></a>
## NFR-01 易用性与低认知负载

- **描述**：减少跨工具转发、窗口切换和状态追踪，允许从摘要进入细节，而非默认展示全部输出。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：完成 AC-01 时无需手动复制任务或执行结果，且能找到整体状态和详细信息。可记录操作次数与使用反馈，但改善基线、样本及目标值待定义（Q16）。
- **来源**：[S01-A1](../00-audit/material-audit.md#s01-a1)，L23–25；[S01-A3](../00-audit/material-audit.md#s01-a3)，L104–144；[S01-A10](../00-audit/material-audit.md#s01-a10)，L609。

<a id="nfr-02"></a>
## NFR-02 状态与传递事实一致

- **描述**：消息流、流程图、泳道和详情不各自维护相互矛盾的任务历史；未完成、失败、待发送与已传递可区分。
- **优先级 / 状态**：P1 / 候选（从共享工作状态与传递状态要求提炼）。
- **验收草案**：同一任务的运行 / 完成 / 失败在各视图一致；任务完成但消息暂缓时，不宣称已送达 ChatGPT。断线、重启、重复结果和恢复后的可靠性目标尚未讨论，不能宣称已具备。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L201、L329–348；[S01-B4](../00-audit/material-audit.md#s01-b4)，L981。关联 FR-05、FR-15、Q08、Q16。

<a id="nfr-03"></a>
## NFR-03 不中断用户注意力

- **描述**：重要状态可被发现，但后台活动不应频繁抢焦点；明确静默时结果仍可用，不自动切换页面或弹出大型提示。
- **优先级 / 状态**：P1 / 候选；保护交流原则来自用户反馈的转述。
- **验收草案**：AC-02 中用户可以继续当前讨论，后台任务完成不抢占输入 / 页面，待处理入口仍能找到。系统自动判断用户正在阅读或思考的能力未被确认。
- **来源**：[S01-A8](../00-audit/material-audit.md#s01-a8)，L533；[S01-C1](../00-audit/material-audit.md#s01-c1)，L1004–1077；[S01-C4](../00-audit/material-audit.md#s01-c4)，L1241–1258。关联 FR-08、FR-10、FR-18、Q03。

<a id="nfr-04"></a>
## NFR-04 信息可追溯与证据不失真

- **描述**：任务、消息、结果、结论保留来源关系；推测不能在跨 Agent 转发后变成已验证事实。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：从结果可找到任务和相关消息，从任务输入可找到来源；运行中任务尚未返回结果时，该结果不被展示为已有证据。哪些原文长期保存见 Q07。
- **来源**：[S01-A7](../00-audit/material-audit.md#s01-a7)，L488–498；[S01-B2](../00-audit/material-audit.md#s01-b2)，L813–821；[S01-C2](../00-audit/material-audit.md#s01-c2)，L1143。关联 FR-15、FR-20。

<a id="nfr-05"></a>
## NFR-05 任务权限与数据边界

- **描述**：遵守用户确认与具体任务限制，按相关性传递上下文，不无条件转发全部历史或源码。
- **优先级 / 状态**：P1 / 候选；安全边界尚非完整安全规格。
- **验收草案**：未确认任务不下发；AC-01 的只读、不得访问真实用户数据限制可在任务输入中审阅；回传内容不默认等于完整源码。实际工具能否强制执行限制须验证，不能以提示文字代替权限保障。
- **来源**：[S01-A6](../00-audit/material-audit.md#s01-a6)，L442–462；[S01-A7](../00-audit/material-audit.md#s01-a7)，L496；[S01-B1](../00-audit/material-audit.md#s01-b1)，L715；[S01-B3](../00-audit/material-audit.md#s01-b3)，L882。
- **缺口**：存储位置、凭据管理、加密、保留期限和删除范围无明确要求，见 Q07；不补写为已存在方案。

<a id="nfr-06"></a>
## NFR-06 协作角色不永久绑定工具

- **描述**：概念上区分全局调度角色与具体工具，保留未来接入其他 Agent / 网页产品的空间，不要求首版支持全部工具。
- **优先级 / 状态**：P2 / 候选 / 未来扩展。
- **验收草案**：需求与概念职责可独立于具体产品说明；新增工具的技术接入契约、兼容性和测试指标待定义，不要求提前实现通用插件平台。
- **来源**：[S01-A6](../00-audit/material-audit.md#s01-a6)，L427；[S01-A9](../00-audit/material-audit.md#s01-a9)，L555–556。关联 FR-24、Q05。

<a id="nfr-07"></a>
## NFR-07 清晰可读的状态反馈

- **描述**：界面克制、紧凑；主体和任务状态易辨认，重要操作有反馈、错误不隐藏，中文、英文和代码可读，日志按需展开。
- **优先级 / 状态**：P2 / 候选。
- **验收草案**：用户能区分主体、待确认、运行、完成与失败，不只依赖大面积颜色；可从摘要展开日志。没有已确认的字号、对比度或响应时间数值。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L112–122；[S01-A4](../00-audit/material-audit.md#s01-a4)，L251–264；[S01-A8](../00-audit/material-audit.md#s01-a8)，L502–536。

## 尚无依据独立立项的质量要求

- **响应性**：材料希望状态可见、任务在后台运行，但没有刷新延迟或交互时延要求；先定义观察目标，不发明性能阈值。
- **恢复可靠性**：没有重启恢复、持久队列、离线补偿、重试次数等契约。
- **软件可维护性**：本次要求文档易增量维护；材料不足以据此制定产品代码覆盖率、部署方式或模块规模指标。

这些是需要讨论的缺口（Q08、Q16），不是已经确认但“待实现”的需求。
