# 功能需求

状态与证据规则见 [README](../README.md#状态与优先级约定)。**以下无历史用户明确确认条款**；P1/P2 为整理排序，验收为草案，不构成实现授权。技术能否满足须另行验证。

<a id="fr-01"></a>
## FR-01 自然对话入口

- **描述**：统一输入默认发给全局调度协作者，当前以 ChatGPT 网页端为主要入口；执行任务运行时用户仍可继续对话。
- **优先级 / 状态**：P1 / 候选。自然对话与执行重叠是场景提案，结尾 B 项仍请求评判。
- **验收草案**：用户输入普通问题不被广播给执行 Agent；已有执行任务不因用户继续讨论而停止；不要求 ChatGPT 改成结构化回复。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L146–166；[S01-B2](../00-audit/material-audit.md#s01-b2)，L791–821；[S01-B4](../00-audit/material-audit.md#s01-b4)，L992。接入 / 会话边界见 Q02、Q06。

<a id="fr-02"></a>
## FR-02 统一多主体消息流

- **描述**：聚合用户、调度者、执行 Agent 及系统重要事件，区分主体与消息类型；默认呈现摘要和关键事件，不倾倒全部终端输出。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：用户在同一消息流辨认消息来源，查看执行结果摘要；长内容可展开，详细执行输出可转到详情查看。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L98–144；[S01-B3](../00-audit/material-audit.md#s01-b3)，L839–854。

<a id="fr-03"></a>
## FR-03 调度意图转为任务草案

- **描述**：保持调度者自然交流，在需要时用独立结构化分析识别行动建议并形成待确认草案；普通命令式文字不能直接触发执行。
- **优先级 / 状态**：P1 / 转述待核验（自然语言与独立分析方向）；提取自动 / 手动触发未决。
- **验收草案**：含行动建议的自然回复可按选定触发方式生成可审阅草案；未确认的提取结果不下发；用户能对照原始建议判断草案是否准确。
- **来源**：[S01-A6](../00-audit/material-audit.md#s01-a6)，L454–462；[S01-B1](../00-audit/material-audit.md#s01-b1)，L691–739。见 Q04。

<a id="fr-04"></a>
## FR-04 任务审阅与人工确认

- **描述**：新任务默认待确认；用户可接受、修改内容 / 执行者或拒绝。自然调度与直接指派都不能跳过确认。
- **优先级 / 状态**：P1 / 候选（设计稿明确条款，缺用户批准）。
- **验收草案**：未确认前执行工具未收到任务；修改后展示将执行的内容和执行者；拒绝草案不启动任务且保留可辨认记录。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L160–189；[S01-A6](../00-audit/material-audit.md#s01-a6)，L440–452。整体计划 / 逐任务确认见 Q01。

<a id="fr-05"></a>
## FR-05 已确认任务分发与状态维护

- **描述**：系统向选定 Agent 分发已确认任务，维护待确认、等待、运行、完成、失败、取消等可辨认状态。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：确认后的任务送达指定执行者；执行工具报告启动、结果或失败后，消息流、任务图与详情反映同一任务状态。运行不以“用户已点击确认”作为充分证据。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L228、L251–260；[S01-B2](../00-audit/material-audit.md#s01-b2)，L743–787；[S01-C4](../00-audit/material-audit.md#s01-c4)，L1273–1285。故障与状态映射见 Q08。

<a id="fr-06"></a>
## FR-06 执行结果收集与分层查看

- **描述**：收集执行 Agent 返回的结果，消息流给摘要，详情可查看完整输出、相关文件或其他成果。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：任务完成后，结果与来源任务相连；不切换执行工具窗口即可看摘要并打开完整结果。示例成果位置能在详情中找到。
- **来源**：[S01-A5](../00-audit/material-audit.md#s01-a5)，L387–413；[S01-B3](../00-audit/material-audit.md#s01-b3)，L825–880。保存范围见 Q07。

<a id="fr-07"></a>
## FR-07 执行结果回传调度会话

- **描述**：系统减少用户手动转发结果给 ChatGPT 的工作，并遵守消息接收策略，不把任务完成等同于已经回传。
- **优先级 / 状态**：P1 / 转述待核验；网页发送及自动续答能力为技术假设。
- **验收草案**：在明确允许发送且接入支持时，选定结果传入目标会话；暂缓时用户可看到尚未发送，不能显示为 ChatGPT 已收到。
- **来源**：[S01-B3](../00-audit/material-audit.md#s01-b3)，L878–926；[S01-C1](../00-audit/material-audit.md#s01-c1)，L1017–1050。Q02、Q03、Q06、Q07 未决。

<a id="fr-08"></a>
## FR-08 独立待发送队列

- **描述**：在后台结果不宜插入当前对话时，待回传内容进入独立于 ChatGPT 原生对话的队列，保护当前讨论。
- **优先级 / 状态**：P1 / 转述待核验；接收判据与模式默认值未决。
- **验收草案**：用户明确暂缓后台接收时，新结果可见而不插入对话；队列保留来源任务与时间，等待用户处理。
- **来源**：[S01-C1](../00-audit/material-audit.md#s01-c1)，L1015–1079；[S01-C2](../00-audit/material-audit.md#s01-c2)，L1143。见 Q03、Q10。

<a id="fr-09"></a>
## FR-09 队列消息人工处理

- **描述**：用户可以预览队列内容、立即发送、延后或取消发送。原稿使用“删除”，其是否只取消待发送项仍需明确。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：预览可知接收者、来源和内容；手动发送作用于选定消息；延后不发送；取消不造成未授权发送。不能把该操作解释成删除任务成果或全部历史。
- **来源**：[S01-C1](../00-audit/material-audit.md#s01-c1)，L1079；[S01-C2](../00-audit/material-audit.md#s01-c2)，L1115–1143。语义与呈现见 Q15。

<a id="fr-10"></a>
## FR-10 完成通知与待发送内容分开

- **描述**：可以告知任务已完成或有待处理消息，而不强迫将内容立即送入 ChatGPT 对话；通知不以大面积抢焦点为默认方式。
- **优先级 / 状态**：P2 / 候选（由后段通知与队列行为区分提炼）。
- **验收草案**：消息待发送时任务仍可显示完成；通知入口与“立即发送”操作不是同一件事；主动静默时仅保留轻量待处理标识。
- **来源**：[S01-C1](../00-audit/material-audit.md#s01-c1)，L1039–1050；[S01-C2](../00-audit/material-audit.md#s01-c2)，L1095–1141；[S01-C4](../00-audit/material-audit.md#s01-c4)，L1241–1248。

<a id="fr-11"></a>
## FR-11 历史与计划共存的流程图

- **描述**：显示已完成、运行、等待及待确认工作，明确区分历史状态与未来计划；节点不是固定 Agent 的化身。
- **优先级 / 状态**：P1 / 转述待核验（原稿称已确定 C 方案）。
- **验收草案**：同一协作视图能辨认已完成任务与待确认计划；状态变化不混淆计划和执行事实；点击工作节点可打开详情。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L203–264。普通对话事件是否作为节点见 Q11。

<a id="fr-12"></a>
## FR-12 任务依赖关系展示

- **描述**：流程图表达顺序依赖、并行分支与结果汇合，不引入复杂条件脚本或循环控制作为首版必需能力。
- **优先级 / 状态**：P2 / 候选；多执行 Agent 并行运行属原稿未来扩展。
- **验收草案**：存在这些关系的数据时，可区分先后依赖、并行与汇合；不会因画出分支就声称任务已同时执行。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L233–243；[S01-A9](../00-audit/material-audit.md#s01-a9)，L555。见 Q05、Q13。

<a id="fr-13"></a>
## FR-13 消息泳道概览与详情

- **描述**：按参与者、时间和方向呈现实际消息传递，概览使用短标签，选中后可查看来源、接收者、时间、摘要与完整内容。
- **优先级 / 状态**：P1 / 转述待核验（概览 / 详情要求）；具体排列和系统泳道候选。
- **验收草案**：能回答“谁何时向谁传了什么”；点击消息可查看详情与关联任务；待发送内容不得误画成已成功传递。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L266–327；[S01-B4](../00-audit/material-audit.md#s01-b4)，L969–981。见 Q14。

<a id="fr-14"></a>
## FR-14 当前选中对象详情

- **描述**：选中任务时显示任务内容、状态、上下文、进展、错误、结果和日志；选中消息时显示消息与关联任务。重要摘要优先，完整信息按需展开。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：切换选择后详情对应新对象；任务完成可先看摘要再展开日志；消息可查看正文、发送 / 接收主体和任务关联。
- **来源**：[S01-A5](../00-audit/material-audit.md#s01-a5)，L351–415。无选中时表现见交互设计。

<a id="fr-15"></a>
## FR-15 任务与消息双向关联

- **描述**：流程图和泳道反映同一工作状态；任务关联多条消息，消息可找到对应任务，不各自形成独立历史。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：从任务能查关联消息，从消息能回到同一任务；结果和状态在各视图不矛盾。
- **来源**：[S01-A4](../00-audit/material-audit.md#s01-a4)，L329–348。

<a id="fr-16"></a>
## FR-16 可调整、折叠和最大化的三栏

- **描述**：左栏交流、中栏理解全局、右栏深入详情；各区域可调整宽度、独立折叠或聚焦最大化，释放区域由可见面板使用。
- **优先级 / 状态**：P1 / 转述待核验（认可三栏及自由控制焦点）；具体行为候选。
- **验收草案**：关闭详情后画布扩展；可专注对话再恢复其他区域；所有区域有恢复入口，布局操作不改变任务或会话。
- **来源**：[S01-A2](../00-audit/material-audit.md#s01-a2)，L47–92；[S01-C2](../00-audit/material-audit.md#s01-c2)，L1089；[S01-C4](../00-audit/material-audit.md#s01-c4)，L1306–1312。

<a id="fr-17"></a>
## FR-17 布局预设与工作空间布局保留

- **描述**：提供全局协作、专注对话、专注流程、专注执行四个候选预设；布局状态在工作空间内保留。
- **优先级 / 状态**：P2 / 候选。
- **验收草案**：预设聚焦对应区域；切换不更换 ChatGPT 会话、不暂停任务；重新打开同一工作空间可恢复其布局。
- **来源**：[S01-A2](../00-audit/material-audit.md#s01-a2)，L92；[S01-C3](../00-audit/material-audit.md#s01-c3)，L1157–1229。见 Q09、Q10。

<a id="fr-18"></a>
## FR-18 独立专注与后台静默控制

- **描述**：用户可以主动暂缓后台消息、静默通知；任务继续运行并收集结果，待回传内容进入队列。视觉最大化与注意力静默独立控制。
- **优先级 / 状态**：P2 / 候选。
- **验收草案**：主动静默后不自动切换页面或弹出大型提示；任务正常完成、结果可查看、待处理数量保留；退出静默后的发送行为按已定策略处理，不假定自动清空队列。
- **来源**：[S01-C4](../00-audit/material-audit.md#s01-c4)，L1233–1258。见 Q10。

<a id="fr-19"></a>
## FR-19 工作空间信息分离

- **描述**：按项目组织主要目标、协作消息、任务流程、Agent 会话关联、成果和关键决策，各工作空间独立。
- **优先级 / 状态**：P2 / 候选。
- **验收草案**：进入不同工作空间可区分各自目标、任务和消息，不误把另一项目的结果带入当前任务；布局保留与 FR-17 配合。
- **来源**：[S01-A7](../00-audit/material-audit.md#s01-a7)，L466–486。创建、切换细节及原生会话映射见 Q06。

<a id="fr-20"></a>
## FR-20 上下文相关性与来源边界

- **描述**：区分原始消息、任务信息、执行结果和用户确认的结论，只向目标 Agent 传递与任务相关的信息并保留来源；不能把未返回结果视为证据。
- **优先级 / 状态**：P1 / 候选。
- **验收草案**：任务输入能追溯到来源；AI 推测不会仅因转发就标为确认结论；执行仍在运行时不展示为已获得完整分析结果。
- **来源**：[S01-A7](../00-audit/material-audit.md#s01-a7)，L488–498；[S01-B2](../00-audit/material-audit.md#s01-b2)，L813–821。内容选择和保存规则见 Q07。

<a id="fr-21"></a>
## FR-21 显式直接指派

- **描述**：用户可在统一输入中明确指定执行 Agent，例如 `@Codex`，生成待确认任务；不另建一套聊天界面。
- **优先级 / 状态**：P2 / 候选（原稿称第一版需要，但未获批准）。
- **验收草案**：显式指派显示目标执行者与任务草案；没有确认仍不执行；普通输入仍默认给调度协作者。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L146–166。多个接收者见 Q12。

<a id="fr-22"></a>
## FR-22 暂停或取消任务的控制能力

- **描述**：用户应能暂停或取消任务；运行中暂停、终止与取消等待任务的精确含义及工具支持尚未定义。
- **优先级 / 状态**：P2 / 候选，行为契约未决。
- **验收草案**：取消未下发任务时不再下发；运行中控制请求的结果可辨认，不能把“已请求取消”当成“工具已停止”。暂停的通过标准待 Q08 定义。
- **来源**：[S01-A6](../00-audit/material-audit.md#s01-a6)，L444–450；[S01-A4](../00-audit/material-audit.md#s01-a4)，L260。

<a id="fr-23"></a>
## FR-23 执行失败可见与后续建议

- **描述**：失败在消息流、任务状态和详情中可辨认；调度协作者可据实际失败更新建议，但不默认自动重试或切换执行者。
- **优先级 / 状态**：P1 / 候选，恢复策略未决。
- **验收草案**：工具报告失败后能找到失败任务及错误信息；失败不显示为完成；后续新执行仍遵守确认约束。
- **来源**：[S01-A3](../00-audit/material-audit.md#s01-a3)，L137；[S01-A5](../00-audit/material-audit.md#s01-a5)，L380–385；[S01-A6](../00-audit/material-audit.md#s01-a6)，L438。见 Q08。

<a id="fr-24"></a>
## FR-24 全局调度建议所需信息

- **描述**：全局调度协作者应能获得目标、已有结果、当前任务状态和可用 Agent 能力，讨论与提出下一步建议；不要求将其角色永久绑定某一产品。
- **优先级 / 状态**：P1 / 候选；信息提供方式及主动建议未决。
- **验收草案**：获得已返回的结果和当前任务状态后，可以提出对应后续建议；界面能显示新的待确认任务而不是直接执行。建议正确性评价方式待定义。
- **来源**：[S01-A1](../00-audit/material-audit.md#s01-a1)，L31；[S01-A6](../00-audit/material-audit.md#s01-a6)，L421–438；[S01-A10](../00-audit/material-audit.md#s01-a10)，L608。见 Q04、Q06。
