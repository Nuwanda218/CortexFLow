# ContextFlow NOW

## 项目一句话定位

面向个人学习、开发与研究的可视化多 Agent 协作工作台：协调现有工具，让工具承担协调，让人专注思考。

## 核心设计原则

以下是已有材料中已整理清楚的设计方向；历史条款仍保留候选或转述待核验状态，不在本页补作用户确认。

- 协调成熟工具，不重新实现或替代它们。
- 智能协作者负责理解与建议，Core 负责确定性的分发、状态和消息协调。
- 执行权由用户掌握，调度建议不等于执行授权。
- 统一工作台分开交流、全局关系与细节，信息按需展开，不要求同时关注全部内容。
- 自动化服务于理解和注意力：保护当前对话，保留信息来源，不把推测或未返回结果当事实。

## 当前唯一主要设计问题

**Q09：首个可用版本要打通哪一个最小协作闭环，哪些能力暂缓？**
